# 内测构建与存档检查

插件正在内测，尚未上线。修复和功能开发保持现有版本号；只有用户明确要求升级版本号时，才修改插件、数据库或内部格式的对应版本。规则以根目录 `AGENTS.md` 为准。

## 构建与存档身份

- 插件版本保持 `0.0.1`，数据库名保持 `bingeup`。
- 公共 JSON 备份和自动快照仅维护当前格式，不编写旧格式迁移或多版本兼容分支。
- 控制记录中的 `revision` 是每次数据提交的序号，用来确认快照是否追上数据库，不是软件或数据库结构版本号。
- Chrome 和 Edge 分别使用各自产物。内测更新继续覆盖原加载目录并重新加载，保留扩展身份。
- 不通过卸载、自动删库、切换数据库名或新增 manifest `key` 处理内测更新。

## 必要检查

```bash
npm run check
npm run build
npm run build:edge
npm run test:storage:restart
npm run test:storage:interruption
```

同配置重启检查在独立浏览器配置中各执行 5 轮，核对学习卡、扩展身份、待备份状态和快照修订，然后注入部分丢失，确认隔离保护。

保存中断检查在独立配置中模拟自动快照写入失败，关闭整个浏览器后重启，确认主数据库设置仍在，快照补写完成。

两项浏览器检查均不使用日常浏览器配置。结果写入 `docs/reports/storage-audit-2026-10-30/evidence/`。缺少浏览器时记录为未通过，不跳过验证后声称成功。
