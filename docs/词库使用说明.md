# 内置词库使用说明

`public/dictionaries/` 存放当前内置词库。

## 维护词库

- `words.json`：有效词条。
- `decks.json`：三个词库及成员关系。
- `questions.json`：每个有效词的固定题组。
- `manifest.json`：内容版本、文件哈希和数量。
- `source-metadata.json`：学习文本的生成版本和复核信息。
- `LICENSE.txt`、`licenses/`：许可声明与原文。

修改词条、词库或固定题组后，运行：

```bash
npm run dictionary:build
npm run dictionary:check
```

构建脚本校验当前内容，并重建 manifest。固定题组的哈希依赖题面、答案、选项、词条内容和题组模板。修改这些输入后，应重新复核受影响题组，并更新哈希。应用在运行时只打乱已复核的选项。

## 构建和安装

```bash
npm install
npm run check
npm run build
npm run build:edge
```

在 Chrome 打开 `chrome://extensions/`，在 Edge 打开 `edge://extensions/`。启用开发者模式，选择“加载已解压的扩展程序”，然后选择对应目录：

- Chrome：`.output/chrome-mv3/`。
- Edge：`.output/edge-mv3/`。

词库随扩展离线分发。词库改变后，重新加载扩展。后台和内容脚本会重新校验 manifest 与文件哈希。

## 导出与导入

设置页的“数据管理”可以导出和导入本地用户数据，包括学习进度、长期设置、网站设置、学习会话和行为事件。内置词库不进入用户备份，用户导入数据也不会替换词库。

导入操作先校验整份备份，再在一个事务内完整替换当前用户数据。校验或写入失败时，当前数据保持不变。

## 来源与许可

学习文本由 AI 生成并经过独立复核，使用 Apache-2.0 许可。`source-metadata.json` 记录生成版本和复核信息；`LICENSE.txt` 与 `licenses/Apache-2.0.txt` 保存许可声明和原文。
