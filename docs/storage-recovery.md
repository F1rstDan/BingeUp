# 存档备份与恢复

学习记录和设置保存在当前浏览器配置中的 IndexedDB。自动快照保存在同一个扩展的本地存储中。扩展会保留当前快照和上一代快照；它们不能代替浏览器配置之外的备份。

## 定期备份

1. 打开设置页的“数据管理”。
2. 点击“导出数据”，将 JSON 保存到浏览器配置目录之外。
3. 保留至少两份不同日期的文件。定期复制到其他设备或自己的备份位置。
4. 升级、卸载扩展、清理浏览器配置或更换电脑前，再导出一次。

备份不含随扩展分发的内置词库。导入时会检查数据结构、单词、词库和学习日志引用。不要手工修改 JSON 中的 ID。

## 显示“自动备份未完成”

主数据库可能已保存成功。先在存档读取状态中核对数据库提交时间、待备份状态和两边修订号，然后点击备份重试。重试备份不会再次提交答案。关闭浏览器后，下一次后台启动仍会检查待备份标记。

## 显示“存档隔离”

扩展已停止继续学习和覆盖恢复快照。先导出当前数据库，再导出可用的当前或上一代自动快照，分别保存。当前数据库导出可能反映部分丢失现场，不能把它直接认作健康备份。

核对备份日期、记录数和诊断原因后，明确选择“导入数据”。导入会替换当前用户数据；导入失败时，数据库事务会回滚。若上次导入或清除被中断，按提示明确重做该操作。

不要通过卸载扩展、移动加载目录或清理浏览器配置来解除隔离。这些操作可能删除或切换存档空间。

## 自动恢复的边界

- 只有全部权威仓库为空时，才自动导入可用快照。只有设置、没有学习卡的快照也可恢复。
- 部分数据仍在时，不自动覆盖剩余数据。扩展会显示异常，并保护已有快照。
- 用户已明确清除的数据不会从旧快照自动复活。
- 整个扩展被卸载、浏览器配置丢失或设备损坏时，本机自动快照也可能丢失。此时需要外部 JSON 备份。
- 若校验失败，保留原文件和诊断信息。不要覆盖唯一备份。
