# 以 IndexedDB 作为本地用户数据的唯一权威存储

学习设置、网站设置、安装引导状态、学习卡、复习日志、学习会话，以及未来由用户创建或导入的单词和词库，需要共同备份、恢复和清除，因此统一保存在 IndexedDB 中，并通过一次事务保持原子性。

`chrome.storage.local` 只保存可安全丢弃的临时运行状态，包括全局冷却、连续跳过次数和临时暂停截止时间，不得用于重建或修改学习进度。

插件尚未公开发布，因此本次直接切换存储结构，不为旧开发数据编写迁移；首次公开备份格式为 v1，兼容承诺从 v1 开始。
