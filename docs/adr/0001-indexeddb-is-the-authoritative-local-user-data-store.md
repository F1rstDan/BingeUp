# 使用 IndexedDB 统一保存本地用户数据

学习设置、网站设置、安装引导状态、学习卡、复习日志、学习会话和行为事件需要跨扩展页面共享。这些数据还需要完整备份、恢复和清除。系统将这些本地用户数据统一保存在 IndexedDB 中。

IndexedDB 提供索引和事务。一次学习提交可以原子写入学习卡与复习日志。备份导入先校验整份数据，再在一个事务内完整替换用户数据；任一写入失败时，数据库保留导入前的数据。

`chrome.storage.local` 保存可以丢弃的临时运行状态，包括全局冷却、连续跳过次数和临时暂停截止时间。临时状态不进入用户备份。学习进度若分散到多个存储，会失去统一事务并增加恢复不一致的风险，因此权威数据只使用 IndexedDB。

`chrome.storage.local` 另外保存一份自动恢复快照。快照不参与常规读取和写入，只在 IndexedDB 整体为空时用于恢复学习卡、复习日志、会话、设置与网站状态。用户明确清除数据时会写入新的空快照和清除标记，避免旧数据在下次启动时复活。
