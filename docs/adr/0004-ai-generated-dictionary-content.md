# 使用 AI 生成学习文本和固定题组

内置词库包含日常高频、四级和六级三个词库。每个词条的学习文本由 AI 生成并经过独立复核，使用一个通用常见义、一个主词性和完整例句。其他常见义只用于详情，不建立额外学习卡。

每个词条使用随包的固定题组，运行时只打乱已复核选项。英文选中文为必填题；中文选英文、语境和拼写题在无法唯一消歧时停用，并按学习卡上的题型顺序回退。

题组保存选项、答案、拼写提示和内容依赖哈希。构建只读取 `public/dictionaries` 中的当前内容并生成 manifest，运行时校验文件哈希。修改词条、干扰项、题面或题组模板后，应重新复核受影响题组，并更新哈希。

语音使用设备本地英语系统语音，由用户手动触发。语音不参与判分，也不作为审校录音。设置页可选择本地英语音色；保存的音色不可用时，选用其他本地英语语音。
