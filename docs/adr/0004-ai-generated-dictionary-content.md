# 使用 AI 重建学习文本并固定题组

旧 ECDICT 快照只保留身份、词频、难度和词库成员关系，不再作为学习文本来源。新词条由 AI 生成并经独立复核，使用单一通用常见义、单主词性、完整例句、翻译、表层词形和固定来源的美式 IPA。其他常见义只用于详情，不建立额外学习卡。

每个有效词使用版本化身份注册表保持旧 ID；错拼和重复身份通过原子转换合并，停用词保留历史但不再调度。正常词的阶段、FSRS 和历史答题事实保持。

题目使用随包的固定题组，运行时只打乱选项。英选中每个有效词必填；中选英、语境和拼写可在无法消歧时停用，并按同卡顺序回退。内容或题组依赖改变时，检查哈希失效并返工，不在运行时组合新题组。

备份继续支持 v1 导入，新导出使用 v2 并携带兼容记录。数据库结构保持版本 5，兼容记录与当前设置分开保存。语音只使用设备本地英语系统语音，手动触发，不参与判分，也不作为审校录音。设置页可选择本地英语音色，默认 Microsoft Zira；保存的音色不可用时回退到其他本地英语语音。

2026-10-24 正式切换后，本决定替代 [ADR-0002](0002-ecdict-is-the-built-in-dictionary-source.md)。全量候选包包含 5,374 个有效词和 5,374 个固定题组，已生成 Chrome 与 Edge 的 schema 2 构建。真实 Chrome、Edge 的安装升级、系统语音和带用户数据的兼容回滚仍需人工验收；未完成前不把整包切换写成全部验收通过。
