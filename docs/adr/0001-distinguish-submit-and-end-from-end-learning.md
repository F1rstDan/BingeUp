# Distinguish submitted completion from ending learning

连续学习中将“提交并结束”与“结束学习”定义为两个不同的动作：前者先提交当前题目并按完成题目处理，后者不提交当前题目、不算跳过并使用默认全局冷却。两者文案相近但会产生不同的复习记录和会话结果，明确区分可以避免 UI 操作或控制器实现把未提交题目误记为完成题目。

2026-10-23：单题“提交”改为保存后直接结束交互并恢复原播放状态。结果改为右下角纸片风格非模态 `status` 提示，位于独立 Shadow DOM 内，无全屏遮罩、不锁定页面滚动、不抢焦点；提示 5 秒后自动关闭，鼠标悬停提示或用户用键盘聚焦提示内按钮时暂停计时。“提交并继续”仍保持暂停并加载下一题，下一题的选择、Enter、拼写和 Esc 操作不受上一题提示影响。“继续答题”从当前页面开始新的主动学习会话，不再次提交旧题。
